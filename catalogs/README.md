# Catálogos editoriales publicados

Snapshots de los textos actuales de los proyectos Digimon y Poka Poka, incluidos
por petición explícita del propietario. Cada carpeta se abre directamente con
Translator y conserva el estado editorial del proyecto al publicarse.

- `digimon/`: Digimon World Re:Digitize PSP, base inglesa v1.1 DUB.
- `pokapoka/`: MonHun Nikki: Poka Poka Ailu Mura G PSP.

Consulta los manifiestos y README de cada carpeta para su ROM base, recuentos y
límites. Los textos no se utilizan como fixtures ni se incluyen en los paquetes de
aplicación. Esta publicación no incluye las ROMs, archivos extraídos o metadatos
locales de reinserción.
