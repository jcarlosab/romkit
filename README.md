# ROMKit

Herramientas de escritorio para organizar una biblioteca de juegos retro.

| Programa | Función | Código y guía |
| --- | --- | --- |
| ROMKit Scraper | Buscar, seleccionar y exportar carátulas para Cannoli, EmulationStation y ES-DE | [tools/scraper](tools/scraper/README.md) |
| Retro M3U Organizer | Organizar discos y generar listas `.m3u` | [tools/m3u-organizer](tools/m3u-organizer/README.md) |

Descarga los ejecutables de Windows en [Releases](https://github.com/jcarlosab/romkit/releases/latest). No necesitan instalar Python.

Cada programa incluye sus instrucciones para ejecutarlo desde el código y reconstruir su ejecutable. La configuración personal, las carpetas de trabajo y los archivos de juegos quedan excluidos del repositorio.

Retro M3U Organizer se distribuye bajo la licencia [GPL-3.0](tools/m3u-organizer/LICENSE).
